# Huellitas — Identidad visual

Sistema de identidad y de interfaz para la app de la veterinaria **Huellitas**.
Estilo **claymorphism**, paleta pastel complementaria y jerarquía tipográfica
serifa gruesa / sans redonda.

## Ver

Abre `index.html` en cualquier navegador. No necesita build ni dependencias.

Con GitHub Pages: Settings → Pages → Branch `main` / `root`.

## Contenido

| Sección | Qué define |
|---|---|
| 01 Logotipo | Huella modular, variantes, área de respiro, usos incorrectos |
| 02 Paleta | Lavanda `#C9BCEB` · Lima `#E5E9A8` · Tinta `#3A3350` + neutros y semánticos |
| 03 Tipografía | Bitter 700–800 (títulos) / Nunito 400–800 (texto corrido) + escala |
| 04 Claymorphism | Receta de sombras, cuatro elevaciones, reglas sí/no |
| 05 Iconografía | Sistema modular de 84 px sobre pastilla de arcilla |
| 06 Componentes | Botones, campos, toggles, slider, chips, tarjetas, tab bar |
| 07 Pantallas | Inicio · Agendar cita · Carnet de vacunas · Teleconsulta |
| 08 Tono de voz | Tierno sin ser cursi, claro primero, nunca alarmista |
